## What survives and what changes

The monochrome instrument-panel idea, Inter typography, generous but purposeful space, small semantic indicators, white page and task-oriented hierarchy survive. The written project rules explicitly refine the original foundation. See DESIGN's source-to-app alias and amendment tables for exact hex values and dimensions.

Resolved drift: original control 5/chip 3 →8px; Table's absent marker →2px ink marker and 14×16 row padding; pale text/disabled mapping → contrast-safe semantic aliases; input borders/outside focus → borderless contextual surfaces/inset ink. Inverse n500 on ink measures4.18:1 and is rejected; inverse-muted n400 satisfies6.01:1 on raised inverse n900. Intrinsic radio/switch shapes are exceptions; no dark-theme scope is added. Toast and tooltip use8px.

Root prototype line14 overrides include pill controls/chips, altered signal yellow and n200 selected fill. These are **excluded legacy styling**, not new exceptions or unresolved alternatives. Prototype conditional selectors also cannot override the written white/gray input hierarchy. Prototype logos, screenshots and decorative imagery do not supersede the owner's pending asset selection.
