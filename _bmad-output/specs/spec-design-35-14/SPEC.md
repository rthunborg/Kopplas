# Live dashboard pipeline

## Why

Entitled existing users need the accepted connected dashboard composition over the delivered E19.1 quote pipeline. The owner approved this existing story's exact seven product paths and its proposed-order amendment on 2026-11-12; no future widgets or producer changes are included.

## Capabilities

- **CAP-1**
  - **intent:** Entitled existing dashboard users can understand current pipeline facts, withholding and freshness, recover a failed read and follow the existing quote destination in an accessible responsive view.
  - **success:** The original seven E35-14-ACs and eleven owned state/test identities are preserved and later demonstrated with actual server projection/payload, existing read-fault fixtures, 360×640/desktop behavior, independent review and the applicable candidate-bound visual gate.

## Constraints

- Exactly five presentation paths and two feature-local E2E paths in source-binding.json are product writes. Ordinary own-story/state/report/evidence metadata is separately enumerated; it grants no extra product writes.
- Preserve the complete seven ACs and Applies/Inherited/N/A obligations in the byte-preserved original companions. Operative contract and dependency-amendment.json control current approval/base/order/allocation, superseding only historical preparation metadata and the 35.13 proposed-order edge.
- Existing E19.1 registry/read/entitlement/money/quote contracts remain authoritative and read-only. Withheld values are absent from payload, absent money is not zero, and only the current real quote destination exists. No E19.2 data/cards, new analytics or financial arithmetic.
- Freeze the existing DashboardPage onboarding host/body/imports/conditions/order/placement, AppShell/nav/root redirect, global styles/fonts/primitives, registry/producers and shared test setup/config/proxy. Scope expansion requires an exact approved amendment; globals are not a feature-local shortcut.
- Consume the existing General browser lane for the new design spec and the dedicated dashboard lane for the original pipeline spec, without changing their selectors/configuration. Runtime/visual evidence remains unearned.
- The original sole story ID is "35-14"; optional checkpoint flags remain absent under owner-approved routine continuation. Native-source booleans are parser provenance, not newly invented preferences.
- Source readiness does not create a native assignment. Qualified source publication, same-primary-common-Git registered paths, independent exact-package review and current capacity/ownership checks precede normal schema-2 admission. Retain every producer/35.2/E15/CRM exclusion and existing claims/resources.

## Non-goals

E19.2 widgets; onboarding/shell/root-route redesign; registry/read/action/permission/schema/money/quote changes; shared fixtures/config/proxy/workflow changes; save/unknown-mutation/receipt/file/dialog/offline features; Phase C surfaces; E15 coordination or reservation release; PR151 rollout/trial.
