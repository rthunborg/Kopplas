One-line: The action trigger — one primary (black) button per view; `signal` yellow is reserved for the marketing CTA.

```jsx
<Button variant="primary" icon="plus">Nytt projekt</Button>
<Button>Avbryt</Button>
<Button variant="ghost" size="sm" icon="filter">Filter</Button>
<Button variant="danger">Ta bort</Button>
```

Variants: `primary` (ink), `secondary` (hairline border, default), `ghost`, `signal` (marketing CTA), `danger` (text-risk, bordered). Sizes 28/34/44px — `lg` for anything a gloved thumb touches. Never two primaries side by side.
