One-line: Label + control + hint/error wrapper — every form control is wrapped in one.

```jsx
<Field label="Projektnamn" hint="Visas på fakturaunderlaget" htmlFor="name">
  <Input id="name" placeholder="Ex. Ombyggnad Kv. Vasa 4" />
</Field>
```

Required fields say `(obligatorisk)` in grey — no asterisks.
