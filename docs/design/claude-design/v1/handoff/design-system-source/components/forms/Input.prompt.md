One-line: Text input with optional leading icon and trailing unit.

```jsx
<Input placeholder="Sök projekt, kund, faktura" icon="search" />
<Input defaultValue="284500" suffix="kr" />
<Input size="lg" placeholder="Antal timmar" suffix="h" />
```

Focus is an ink border + 1px ring, never a coloured glow. Use `size="lg"` in field views.
