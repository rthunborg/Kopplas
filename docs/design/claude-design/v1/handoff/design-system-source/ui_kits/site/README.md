# UI kit — Kopplas marketing site

One-page marketing site (Swedish). Open `index.html`.

| File | Section |
|---|---|
| `SiteHeader.jsx` | Sticky glass header, wordmark, nav, signal-yellow CTA |
| `Hero.jsx` | Eyebrow, 104px display headline, full-bleed image placeholder with scrim, three proof metrics |
| `Chain.jsx` | The five-phase chain as an interactive selector + three feature cards |
| `Pricing.jsx` | Three plans; the recommended plan is an inverse (`data-theme="inverse"`) card |
| `Footer.jsx` | Inverse demo-booking block + hairline footer |

Nav links scroll to sections. The phase chain and the pricing period switch are live.

**Imagery is placeholder only** — grey blocks captioned with what belongs there. No photography was provided with the brand.
