## Required behavior

role and fixed argv digest, actual launch state, close/process-error event,
code/signal, parent wait outcome, during/after-wait phase and owned/output settlement.
The code is a native0..255 integer, null or UNKNOWN; signal is a finite POSIX enum,
NONE/OTHER/UNAVAILABLE. These facts concern the owned pnpm process, not an inner
Vitest worker. Missing or malformed facts remain UNKNOWN; no native error text,
getters, environment, CWD, SQL, assertion payload, test title or raw output survives.

Text emitter and inner runner cause are always UNKNOWN. Only five fully anchored
allowlisted heading/summary shapes may increment per-STDOUT/STDERR occurrence
counts; rendered printed totals are not retained. Perfect forged output remains
untrusted and cannot set native fields. Zero matches never proves no error.
Existing privacy-first observation runs normally before optional shape inspection.

New metadata parsing accepts complete lines <=4096 UTF16 code units and at most
8,388,608 total code units; counters saturate255 with a saturation flag. Fragments,
trailing partial input and oversize lines do not become reconstructed matches.
New serialized record <=4096bytes. Existing privacy scanning still covers ALL
output after the diagnostic budget is exhausted. No raw line/hash/ring buffer,
new artifact, logger, process, timer, retry or queueing framework is added.

COMPLETE requires existing verified owned-group AND output/observer settlement,
full bounded coverage and no known privacy hit. A known privacy hit at any point
before freeze withholds ALL shape counts (null) and sets UNAVAILABLE, including
hits after earlier matches. Unverified output/persist settlement likewise means
UNAVAILABLE/null. PARTIAL/TRUNCATED are permitted only when remaining settlement
is verified and privacy is clear. Freeze once only after qualified settlement;

the unchanged privacy observer still runs/rejects normally. Late unobserved facts
