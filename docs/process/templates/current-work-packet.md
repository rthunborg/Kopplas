# Current work packet template

Maximum 12000 Unicode scalars; two-page target. Replace current facts rather than
append progress. Archive superseded revisions privately with immutable pointers.
Never include secrets, raw logs, payloads or personal records. Each required key
below occurs exactly once with a nonempty value; replace bracketed guidance.

Revision: [UTC time and packet revision; superseded immutable pointer]
Authority: [approved scope and explicit current coordinator; immutable native owner distinction]
Ownership: [assignment/story or legacy reservation, actor/session/canonical task, owned paths/domains; branch/worktree/common-dir; claim generation/plan]
Holds: [hold revision, explicit ACKs, release/resume disposition; missing ACK means pending]
Candidate: [full SHA/tree, source/base/merge identities; dirty fingerprint where needed]
Pins: [full helper/spec hashes and immutable source references]
Running: [actual commands/jobs/session IDs, named observer, resource owner references; none only when verified]
Dimensions: [implementation; verification; human acceptance; integration/deployment; process closeout, each independently]
Blockers: [category, first native failure versus wrapper result, executed/failed/skipped counts or unknown; affected ACs; smallest repair]
Evidence: [immutable restricted evidence paths/checksums, frozen allocation and all gate/acceptance pointers]
Next action: [one authorized command/owner, revision ACK required, exact resume condition]

This packet grants no ownership transfer, claim mutation, release, acceptance or
resource custody. Refresh changed facts at use. See the
[operating policy](../bounded-workflow-operating-policy.md).
